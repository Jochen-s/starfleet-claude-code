# Level 01 – pencil & paper platformer

A single-file HTML5 canvas game that copies the hand-drawn "Level 01" sketch 1:1.
All object coordinates in `index.html` are the pixel coordinates of the original
drawing, so the layout matches the paper.

Open `index.html` in any browser (no build step, no dependencies).

- **Menu**: Start Level 01 / Controls / Credits (arrow keys + Enter, or click)
- **Move**: Arrow keys or A / D, **Jump**: Space / W / Up (hold for a higher jump)
- **Pause**: Esc, **Restart**: R
- **Goal**: collect the coin ("Coins 01"), avoid the spikes and spiky critters,
  reach the door at the top left. The clouds are the "Hintergrund" (background).
